# robinsavages

Danny's fantasy football GM kit for the West Van Super Studs (Sleeper, 2026, superflex PPR).

    cd ~/Code/robinsavages
    python3 scripts/sleeper.py roster     # pull the roster from Sleeper
    claude                                # open Claude Code; CLAUDE.md has the plan

- `app/gm.html` — phone GM app (published on claude.ai)
- `app/war-room.html` — draft-night board
- `scripts/sleeper.py` — Sleeper API helper
- `docs/league-context.md` — league facts, IDs, draft strategy
